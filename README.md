# Signmaster — Digital Signature Generator

A lightweight web application built using **HTML, CSS, and JavaScript** that allows users to create smooth digital signatures and download them in **PNG format**.  
Perfect for signing documents online without installing any software.

---

## 🚀 Features
- Draw digital signatures using mouse or touchscreen  
- Smooth, pressure-free drawing canvas  
- Clear/Reset option  
- Download signature as **transparent PNG**  
- Responsive and minimal UI  

---

## 🛠️ Tech Stack
- **HTML5 Canvas**
- **CSS3**
- **JavaScript (Vanilla)**
